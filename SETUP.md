# Installation

Create or open the special GitHub profile repository:

`SANAULLAH-AI/SANAULLAH-AI`

Upload these files directly to its root:

- README.md
- hero.svg
- footer.svg

No folders are required.

This final version intentionally contains only the profile information supplied by the user.

Excluded:
- GitHub Analytics
- repositories
- repository cards
- project lists
- contribution graphs
- streaks
- statistics
- extra profile sections

The hero uses animated SVG for the moving crystal/prism effect because GitHub README rendering does not support arbitrary JavaScript, CSS, or WebGL.
